Algorithmic Adjustment

Python implementation for the new yield calculator:


def calculate_annual_yield(principal, rate, years):
    """Calculates compound interest yield"""
    
    # Apply compound interest formula
    final_amount = principal * (pow((1 + rate / 100), years))
    
    return round(final_amount, 2)
